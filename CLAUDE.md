# psyteeth.ru — сайт «Психостоматология №1»

Статический сайт (перенесён с Tilda). Чистый HTML/CSS/JS, без сборки и зависимостей.
Хостинг: GitHub Pages, репозиторий `psyteeth/rusite`, ветка `main`, корень.

- Сейчас (тест): https://psyteeth.github.io/rusite/
- Позже: https://psyteeth.ru (живой psyteeth.ru пока на Тильде, DNS не трогать)

## Где что лежит
- `index.html` — главная (лендинг: о проекте, особенности, цены, отзывы, команда, блог)
- `io/index.html` — лендинг «Исцеление отношений» (psyteeth.ru/io)
- `tpost/<slug>/index.html` — статьи блога. URL совпадают с тильдовскими, не переименовывать папки
- `assets/css/style.css` — все стили; `assets/js/main.js` — меню, слайдер блога, лайтбокс фото
- `assets/img/` — все картинки
- `404.html` — страница ошибки + редирект старых ссылок `/tpost/<uid>…` на статью
- `sitemap.xml`, `robots.txt`, `.nojekyll`

## Правила
- Все пути внутри сайта **относительные** (`assets/...`, `../assets/...`, `../../tpost/.../`), никогда не начинать с `/`: сайт открывается и из подпапки `/rusite/`, и с корня домена.
- Исключения: canonical, og:url, og:image и JSON-LD — абсолютные `https://psyteeth.ru/...` (так и задумано).
- Тексты — авторские. Править только то, что просит пользователь; стиль, тире и пунктуацию не «улучшать».
- Не добавлять зависимости от Tilda (tildacdn, tildaapi) и внешних CDN. Новые картинки — в `assets/img/`.
- Файл `CNAME` не создавать, пока пользователь не скажет переезжать на psyteeth.ru.

## Новая статья
1. Скопировать папку любой статьи в `tpost/<новый-slug>/`, поправить `<title>`, description, og-теги, canonical, JSON-LD, заголовок, дату, обложку и текст в `.post__body`.
2. Фото: `<figure><img src="../../assets/img/файл.jpg" alt="..." loading="lazy"></figure>`.
3. Добавить карточку `<a class="card" href="tpost/<slug>/">…</a>` в `#blog` на `index.html` (первой — самая новая) и ссылку в `sitemap.xml`.
4. Добавить uid/slug в карту редиректов в `404.html`, если у статьи есть короткий id.

## Проверка
```bash
python3 -m http.server 8935
```
→ http://localhost:8935. Проверить, что нет битых картинок/ссылок и ошибок в консоли, и посмотреть на ширине ~1280 и ~375.
Быстрая проверка путей: ни одного `src="/` или `href="/` (кроме `//`) в html-файлах.

## Публикация
Commit + `git push origin main` → GitHub Pages пересобирается сам за ~1 минуту.

## Переезд на psyteeth.ru (когда пользователь скажет)
1. Создать `CNAME` со строкой `psyteeth.ru` (или вписать домен в Settings → Pages).
2. DNS у регистратора (делает пользователь): A `@` → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153; CNAME `www` → psyteeth.github.io; старые записи Тильды удалить.
3. После проверки домена — Enforce HTTPS. Тильду отключать только после этого.
